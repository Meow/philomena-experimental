## Index summary

No new index candidate is supported by a master -> context-logic query-shape
delta. All changed selective predicates are covered by existing unique/PK/FK
indexes (`tags.slug`, `tags.name`, `tags.aliased_tag_id`, implication and
tagging tag-ID indexes, and dependent tag-ID indexes). The notable uncovered
array predicates on `filters.hidden_tag_ids`/`spoilered_tag_ids` and the
`images_count` ordering scan predate this refactor and should only be considered
as separate workload/performance work with plans and cardinality evidence.

The visibility predicates introduced in alias/delete batching (`images.id` and
`hidden_from_users`) alter correctness and lock behavior; they are not evidence
for a new index because image IDs are primary keys and the base taggings scan is
already indexed.
